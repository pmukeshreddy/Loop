# M6 shared teacher hook and optional Mode A implementation plan

> Execute inline using the executing-plans and test-driven-development skills;
> obtain one independent final review. The user's confirmed scope is shared hook
> plus optional Mode A; full-vocabulary JSD stays in M7.

**Goal:** add a local frozen-base teacher hook and a one-update Mode A correctness
smoke using pinned prime-rl model/LoRA/loss code, with server entry points.

**Architecture:** use original verifiers per-turn token records as separate
unpacked samples, replacing only the initial prefix. A serialized training step
runs student then privileged teacher, restores adapter/routing/mode/RNG state,
and calls prime-rl's native sampled-token loss. A synchronous one-update runner
is the M6 integration boundary; it does not modify upstream async transport or
pretend its TrainingSample schema carries teacher prefixes. Future async/multi-
GPU integration is separate work; M6 supports dense MultiLoRA, eager, one GPU.

**Tech stack:** existing pins, torch 2.11.0 CPU on macOS for tensor tests; upstream
2.11.0+cu128 on Linux. Exact CPU additions are pinned separately.

**Spec:** docs/SPEC.md §6.1–6.3; AGENTS.md M6; user's Mode B architecture change.

## Global constraints and rulings

- No teacher API/server; generation endpoints only. No rewards, SFT or JSD.
- Keep non-LoRA weights frozen and modules_to_save empty. Teacher has no grads.
- Preserve suffix IDs; root completion masks only; no re-tokenization fallback.
- M5 real gate must pass before real OPSD, including smoke. No coverage bypass.
- Server execution remains deferred until its real prerequisites exist. CPU
  synthetic models and HTTP responders must never count as pretrained smokes.
- Continue in the existing shared, untracked project as M0–M5; no worktree,
  commit, push or repeated design approval. Existing spec and user confirmation
  authorize implementation. Code/test limits must be recorded, not silently
  passed through unsupported compile/FSDP/MoE configurations.
- The pinned trainer has no disable_adapter context. Add a true dense-linear
  bypass so NaN/Inf adapter residuals cannot contaminate teacher logits; also
  save/restore the pinned in-place scaling/routing tensors. Restore before any
  student backward/checkpoint recomputation.

## Review focus

Token clipping/missing IDs must fail closed; later-turn prompts may rewrite
history so never assume append-only packing. Exceptions must restore every
module flag and global tensor reference. Empty masks must not update weights.
Teacher logits must remain base-only after optimizer changes. Operational gate
evidence, model revisions and small-before-large smoke order must be checked.
