# M7 full-vocabulary JSD and token gate implementation plan

> Execute inline with executing-plans and test-driven-development, then obtain
> one independent final review. The existing SPEC and explicit M7 instruction
> authorize execution; no new design approval, commit or worktree is needed.

**Goal:** implement OPSD (§6.3–6.4), exact full-vocabulary beta=0.5
JSD and an optional detached token gate, selectable by config.

**Architecture:** reuse M6 aligned per-turn samples and serialized frozen-base
teacher context. Run student and teacher backbones without a vocabulary head;
select aligned assistant hidden rows, then project and score bounded row chunks.
A first-order custom autograd function saves hidden states and the frozen head
reference, recomputing each chunk during backward so chunk graphs do not build
up. Integrate OPSD with the existing one-update smoke and strict preflight.

**Tech stack:** existing immutable prime-rl/Verifiers/Qwen pins; local torch
2.11.0 CPU tests and the pinned Linux/CUDA runtime. No new dependencies.

**Spec:** docs/SPEC.md §6.1–6.5; AGENTS.md M7; user-authorized server implementation and local CPU checks.

## Constraints and decisions

- Full-vocabulary JSD is the OPSD objective. No scoring API/server, SFT or rewards.
- Same recorded suffix IDs; teacher prefix and causal positions differ correctly.
- Base/head frozen; teacher detached; restore adapter/routing/modes/RNG before
  backward. Keep M6 eager single-GPU/dense-adapter limits.
- JSD uses all vocabulary entries at temperature; normalize by selected token
  count, including when gating. Gate = sigmoid(k*(logpT-target - logpS-target)),
  detached; default off, positive finite k default 1.0, beta fixed 0.5.
- Projection/loss workspace O(chunk_size*vocab), plus existing head weights,
  selected hidden states and student backbone graph. No whole sequence logits,
  top-k approximation, full-head FP32 copy, or sum of retained chunk graphs.
- Only first-order optimizer gradients are supported by the recomputing loss.
- Reuse one-task/one-update runner. No async training, broadcast/resume, M8
  monitoring or GRPO additions. Preserve unset thresholds and coverage checks.
- For OPSD 27B, require a real small OPSD smoke with matching objective/gate
  convention. CPU fixtures cannot satisfy that requirement. Server execution
  requires the configured endpoints, real gate evidence and pinned runtime.
- Work in the existing untracked shared project; record evidence in logs/plan,
  not commit-oriented skill scripts. Preserve all prior logs and source pins.

## Review focus

1. Detached gate gradients differ from differentiating the gate itself; numerical
   tests must hold weights fixed in the independent gradient reference.
2. Chunking loss after full projection or retaining all chunk autograd graphs
   violates memory bounds; observe real projection and saved-tensor shapes.
3. BF16/FP16 inputs and extreme finite logits need FP32 normalization; float64
   reference/gradcheck must retain precision. Reject invalid selected rows.
4. Model head must be frozen ordinary linear with no bias/softcap/adapters;
   bypassing a custom head silently would change the distribution.
5. OPSD must be selected end-to-end and small-smoke evidence must establish
   the same objective; config labels alone must not imply runtime success.
